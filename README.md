# Translator

Транслятор из Python-подобного языка в C++

## Возможности 
- Нестрогая типизация
- Типы: целое число, дробное число, истина/ложь, строка
- Вывод в консоль
- Арифметические и логические выражения
- Циклы и условия
- Функции

## Пример кода
```
fn fib(n) {
  if (n <= 0) return 0;
  if (n == 1) return 1;

  return fib(n-1) + fib(n-2);
}

i = 0;
while (i <= 15) {
  print "fib(" + i + ") = " + fib(i);
  i=i+1;
}
```
